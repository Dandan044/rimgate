# Rimgate · 防线

Godot 4.7.2 / Windows x64。原创俯视战术防御 Demo，6 名守军在一张固定地图上守护核心 8 分钟，迎击 3 波敌人。经营、建设和长期存档留待后续版本。

当前源码处于第三版 Demo v0.3 验收阶段；范围见 [第三版规划](DEMO_V3_PLAN.md)，验收进度见 [第三版验收](docs/V3_TEST_REPORT.md)，操作见 [第三版游玩说明](docs/PLAY_V3.md)。完整游戏方向见 [设计记录](GAME_DESIGN.md)。[第二版规划](DEMO_V2_PLAN.md)、[第二版验收](docs/V2_TEST_REPORT.md)及第一版历史资料保留。

第三版已接入连续掩体、人体挡弹/友方贴近豁免、分级姿态压制、自动预装、最终概率预览、右拖队形、紧凑HUD及定稿美术。候选程序的最终交付以测试报告与版本清单为准，保留第二版可玩包。

## 游玩

解压 Windows 包，运行 `Rimgate.exe`，并保留相邻的 `Rimgate.pck`。不需要安装 Godot，也不需要联网。详细操作见 [游玩说明](docs/PLAY_V3.md)。

- 左键选人，拖框多选，Shift 增选；右键地面移动，右键敌人指定攻击。
- 多选后按住右键拖出队列，调整展开方向与间距，松开确认；暂停时立即显示各人独立格心落点。
- 右键机枪或迫击炮选择操控或补给。机枪限 1 人，迫击炮限 2 人；工事需要人员在岗才能工作。
- 选中工事后右键敌人指定该工事目标。迫击炮也可点击“轰击”，再左键选择落点；每次命令仅发射一枚，爆炸和弹片会误伤友军。
- 新一次右键替换旧菜单或选点状态，并立即处理本次点击，无需先左键空白处。
- 右键伤员选择现场急救；对昏迷者可以救援至救护区。急救只止血，生命缓慢恢复。
- HUD调整征召、姿态、风格及独立停火/目标策略。强制蹲卧切换打断一次，之后可继续兼容行动；蜷缩停止行动，溃逃自动撤离并暂时不能征召。
- 选人或有人操作的工事后悬停敌人，显示当前快照的最终概率，Alt展开明细；迫击炮显示爆炸覆盖概率。出血状态显示预计死亡时间。
- Space 暂停/继续，WASD 或中键平移镜头，滚轮缩放，Esc 打开菜单。
- 开局处于准备暂停；布置命令后点击“开始防守”。暂停时可以下命令，恢复后执行。
- 守到 8:00 获胜；核心被摧毁或全员死亡则失败。结果页可以重开。

可以先让两人操作机枪、一人操作迫击炮，其余三人警戒侧翼并补给、救援。迫击炮增加副手可缩短作业周期。左机枪覆盖西北、右机枪覆盖北面，各自保持120°射界；开放的L/U形阵地保留通路与侧后暴露。前沿守军尽量与己方机枪弹道错开，炮击前也要注意友军位置。

连续同属性掩体按弹道穿越段结算，隔开的防线分别参与；人员可以挡弹，贴近友方非目标人员有局部出射豁免。常规步枪约3秒一轮，压制更低精度，谨慎更高精度。自动姿态选择定点交火时能开火的最低姿态，手动锁定不擅自起身；工事岗位不满足姿态时暂停但保留分配。空闲征召人员及有人操作的工事会预装，迫击炮仍一条命令一发。

## 源工程

用Godot **4.7.2标准版**导入 `project.godot`，按F6/F5运行。使用Compatibility和纯GDScript，不需要.NET。默认使用已定稿的分层小人、A地表、沙袋v4与野战军用建筑；暂停菜单的“小人外观”可切回初版。素材来源见 [ASSETS](docs/ASSETS.md)。

第三版程序目录为 `build/release_v0.3_windows/`，同目录EXE/PCK需成对保留。身体、上衣、裤装、防弹衣和头盔独立叠加，身份四特征独立组合；敌方使用固定整人姿态和独立武器，见 [分层约定](docs/PAWN_LAYER_CONTRACT.md)。此前 `build/pawn_art_demo/` 和 `build/pawn_art_evidence/` 是历史人物预览，不代替第三版验收。

固定60Hz仿真位于`scripts/sim`，界面与表现位于`scripts/ui`。活动单位独占格子，格心之间连续移动，显示帧继续插值；画面和音效不决定伤害，固定种子104729。美术与实时连续感的参考依据见 [调研记录](docs/REFERENCE_REVIEW.md)，新增声音来源见 [音频记录](docs/AUDIO_V2.md)。

```powershell
# -Godot 可指定自己的 Godot 4.7.2 console 路径。
powershell -ExecutionPolicy Bypass -File tools/test.ps1

# 将官方同版本 export_templates.tpz 放到 .tools 后，只提取 Windows 模板。
python tools/extract_templates.py
powershell -ExecutionPolicy Bypass -File tools/build.ps1
```

本地引擎、导出模板、`.godot` 缓存与 `build` 不纳入 Git。导出程序与源码 ZIP 输出至 `build`。

发布要求先提交工程，源码ZIP取自该提交。`tools/build.ps1 -Version 0.3.0 -ExportOnly` 导出并记录产品指纹；测试同一EXE/PCK后用 `-Version 0.3.0 -PackageOnly` 原样打包，再运行 `python tools/verify_release.py --version 0.3.0`。清单分别记录导出与文档所在提交；打包不代替测试，详见 [构建来源](docs/V3_BUILD_PROVENANCE.md)。
