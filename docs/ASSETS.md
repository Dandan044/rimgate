# Rimgate Demo 资源来源与制作说明

2026-10-11。所有图片、音效和字体已保存在工程内，运行不联网。

游戏使用 [Godot Engine](https://godotengine.org/license/)；引擎MIT许可随包保存于 `docs/GODOT_LICENSE.txt`，第三方组件说明见该官方许可页与 [官方分发说明](https://docs.godotengine.org/en/stable/about/complying_with_licenses.html)。字体许可证另随包保留。

当前运行版本引用 `assets/art/vector/` 的原创 SVG 人物与工事，详细规格见本文末尾的“原创矢量基础样板”。地面由静态 CanvasItem 绘制，使用稀疏 SVG 草丛点缀；不再引用旧 PNG 地形图集。下面保留旧素材来源记录，便于回溯。

## 旧版 PNG 角色与工事（留作回退）

使用 Codex 内置 image_gen 工具和 imagegen 技能生成，未使用商业游戏原资产。生成后仅复制原始 PNG，未用 Python 重绘、裁切、修补或修改图像。Godot 在运行时通过纹理区域读取图集。

- `assets/art/friendly_atlas.png`：友军角色，5×2 图集，10 个身体姿态。
- `assets/art/enemy_atlas.png`：普通敌军，5×2 图集，10 个身体姿态；侧翼敌军复用。
- `assets/art/heavy_atlas.png`：重装敌军，5×2 图集，10 个身体姿态。
- `assets/art/props_atlas.png`：工事、武器与补给物，4×4 图集，16 格。
- `assets/art/terrain_atlas.png`：草土、道路、混凝土地面，3×1 图集。
- 五份对应的 `*_prompt.txt` 保存完整生成提示词。首次输出保留于 Codex 默认生成目录，项目引用的副本均在 `assets/art/` 内。

角色第一行为站立前/右/后/左、卧倒；第二行为蹲伏前/右/后/左、昏迷。友军生成的第一格实际为朝下，因此渲染按实际图像方向映射。站蹲以脚点定位；卧倒与倒地以中心定位，武器独立旋转。各人物共享外观，通过编号与阵营区分。避免每套装备重复绘制动画。

工事图集逐行内容：

1. 沙袋、混凝土墙、2×2 箱体、通用残骸。
2. 核心设施、核心损毁、机枪底座、机枪枪身。
3. 迫击炮底座、迫击炮炮管、步枪、迫击炮弹。
4. 机枪弹箱、炮弹箱、医疗床、静态岩石。

区域读取从每个格子的四边缩进，排除部分生成图集边缘的细线；原始素材仍完整保留。PNG 无损导入、线性采样，默认不开 mipmaps。地面采用生成的地形图集铺设；阴影、轮廓、选择、射界、弹道与爆炸粒子使用 Godot 简单图元。图像尺寸及透明轮廓不改变仿真占地、高度、体积、掩护与受击判定。

## SVG 图标与声音

`assets/generate_support.py` 是可复现的原创辅助资源源文件，只生成 SVG 和 WAV，不处理 PNG。17 个 SVG 图标分别为移动、攻击、停止、操控、救援、急救、站立、蹲伏、卧倒、三种作战风格、流血、倒地、溃逃、受阻和暂停。

14 个原创音效均由固定随机种子的噪声、包络和正弦波程序合成，48 kHz、16 bit、单声道：步枪两种、机枪两种、迫击炮、爆炸两种、建筑命中、人体命中、换弹、命令确认、告警、胜利、失败。没有采样商业音源，也没有配音与背景音乐。界面使用有限声音池，按仿真事件 serial 去重，不重复播放旧事件。

## 中文字体

`assets/fonts/NotoSansCJKsc-Regular.otf` 来自 [Noto CJK 官方仓库](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese)，许可证保存在同目录 `LICENSE.txt`。字体随游戏分发，不依赖玩家电脑已安装中文字体。

## 美术与仿真接口

`scripts/ui/world_view.gd` 只读世界状态并消费开火、命中、伤害、爆炸和摧毁事件；不产生游戏伤害。`scripts/ui/battle_screen.gd` 仅向 `world.submit` 提交命令；暂停、结果与重开通过公开世界接口执行。素材替换不修改固定种子或战斗计算。

实际视口截图入口：`capture_review_frame(path)`。`apply_review_orders()` 使用真实岗位与移动命令，不修改 HP、弹药或伤害。命令行支持 `--review-auto --review-time=秒 --review-zoom=倍率 --review-capture=绝对路径 --review-quit`，用于复现渲染检查；运行参数置于 Godot `--` 之后。独立 QA 仅在提供 `--qa-mode=...` 参数时动态加载。

UI 契约检查脚本为 `scripts/ui/ui_contract_test.gd`，验证暂停与岗位预约、满员禁用、姿态与作战风格的待执行显示、迫击炮子命令、重开清理和所有资源导入。真正鼠标输入由独立运行时 QA 检查；按钮事件使用事件自身的视口坐标，经相机画布逆变换转换为格坐标，不依赖操作系统光标即时位置。

## 2026-10-11 美术方向修订：原创矢量基础样板

新资源位于 `assets/art/vector/`，由原创 SVG 路径与几何形状直接绘制，没有复制 RimWorld 图像，也未对旧 PNG 重绘。方向依据 [参考复盘](REFERENCE_REVIEW.md) 与 [开发者关于简洁、图标化与矢量观感的说明](https://ludeon.com/blog/2013/12/rhopunzel-in-the-house/)。旧 PNG 图集作为可回退的旧版本素材保留，不再作为本次美术验收目标。

人物使用大头和简化躯干、统一粗描边、阵营色块及一层明暗，不绘制完整腿部、靴子、迷彩、铆钉或织物细纹。友军青灰衣与浅色头盔、普通敌军陶土红衣与暖色头盔、重装敌军宽肩灰甲与闭合面罩。武器保持独立图层。

- `friendly_atlas.svg`、`enemy_atlas.svg`、`heavy_atlas.svg`：`width=1280 height=512`，`viewBox="0 0 320 128"`。5×2 严格等格，逻辑单格 64×64，Godot 栅格化单格 256×256。普通站立轮廓约 40×49 逻辑像素，重装约 44×49；描边约 3。透明背景且没有格线。新图必须读取完整等格，无需沿用旧 PNG 的裁边。
- 人物帧索引 0–4：站立朝下、右、上、左、卧倒朝右；5–9：蹲伏朝下、右、上、左、倒地朝右。站立与蹲伏锚点 `(32,56)`，卧倒/倒地锚点 `(32,32)`，均为单格逻辑坐标。站立武器参考挂点约 `(32,40)`，蹲伏约 `(32,45)`；挂点只是表现参考，不改变仿真受击点。
- `props_atlas.svg`：`width=1024 height=1024`，`viewBox="0 0 256 256"`。4×4 等格，逻辑单格 64×64，栅格化单格 256×256。沿用旧图索引：0 沙袋、1 墙、2 箱体、3 残骸、4 核心、5 核心损毁、6 机枪基座、7 机枪枪身、8 迫击炮基座、9 迫击炮炮管、10 步枪、11 炮弹、12 机枪弹箱、13 炮弹箱、14 救护垫、15 石块。建筑与物品一般按 `(32,32)` 定位；机枪基座中心 `(32,30)`，迫击炮基座中心 `(32,33)`。
- 枪炮图均朝右。机枪枪身旋转参考锚点 `(22,32)`、迫击炮炮管 `(16,32)`、步枪 `(25,32)`、炮弹 `(32,32)`。将对应点平移到炮座或人物挂点后旋转；不要将完整图集原点作为旋转轴。
- `grass_01.svg`：`width=256 height=256`，`viewBox="0 0 64 64"`，锚点 `(32,50)`。仅含两丛低对比草叶，适合稀疏摆放；不应密集铺成均匀噪点。地面主色与大块地表变化由场景绘制。

验证：五个 SVG 均经 Godot 4.7.2 的 `Image.load_svg_from_string()` 实际载入，返回 `OK`，尺寸与上述一致；栅格化临时预览已目视检查轮廓、四向、姿态、色板及图集格边。临时 QA PNG 位于系统临时目录，不作为工程素材。实际战场接入、720p/1080p 尺度与移动观感仍由总负责人在小场景验收，不能仅凭图集预览宣布修订完成。

## Demo v0.2 表现与声音修订

保留上述 SVG 人物轮廓、阵营配色、图集尺寸、平涂和线性采样。工事图集新增统一左上光源的顶面亮边、右侧暗面和少量接缝；场景补充接地阴影、低对比地表色块及道路磨损。装饰不参与寻路、占位或遮挡，静态地面仍由独立 CanvasItem 缓存。

`scripts/sim/weapon_pose.gd` 为仿真与显示共享的武器锚点来源，位置单位为地图格。步枪按人物姿态求手部挂点及枪口；机枪和迫击炮按炮座旋转点求枪口。显示层只叠加短暂整枪后座，不修改真实发射点；工事固定射界 `facing` 与实际武器方向 `weapon_facing` 分开。枪焰使用开火事件的实际枪口位置与瞄准方向；受伤事件按单位编号驱动短暂红色叠色和轻微身体抖动，脚点及受击范围保持仿真值。

选中或悬停单位的瞄准锥由真实 `weapon_state`、`aim_fraction`、`stability` 驱动；治疗进度和动作由真实任务阶段及计时驱动。动作不反向决定伤害、瞄准或止血完成时间。暂停时插值、特效和战场音频冻结，恢复不重复消费旧事件。

v0.2 的武器、爆炸与实物动作声音替换为已许可音源的离线混音，原始来源、许可及制作过程见 [声音资源说明](AUDIO_V2.md) 和 `assets/audio/LICENSES.txt`；本文件上方的14个程序合成声音描述属于v0.1历史。运行时加载24个声音，固定24个空间声音节点，按事件序号去重并等待显示弹丸到达再播放命中声音。使用距离衰减和左右声像；重要告警可以抢占低优先级脚步、枪声，普通枪声不会抢占告警。脚步区分草地与混凝土，并使用微小变体；新增医疗、接管、不同材质命中、机枪装填与迫击炮装填声音。所有随机表现变化与仿真随机种子分离。
