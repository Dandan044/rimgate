# AI角色方向采纳：额头修订与换装审阅

2026-10-13，用户采纳上一轮AI画风，要求修正头发/额头衔接，基础身体采用最简白色T恤和短裤，并展示不同装备。本轮沿用原五官、脸型和三种体型方向，不替换游戏运行时素材。

## 审阅图

- `hair-before-after.png`：三种发型的修改前后。五官图层保持不变，增加低位刘海，头顶起点从112下移到132，脸型显示高度从225收紧到205；下巴和眼线仍沿用共同坐标。
- `equipment-review.png`：三种人物 × 基础/轻装/标准/重装，共12个实际组装结果。同一行四项身份特征一致，只变装备。
- `body-equipment-layers.png`：独立基础身体与三类衣装的原始图集。

## 本轮源部件

- `features.png`、`faces.png`：沿用采纳版五官和脸型，未重新生成身份。
- `hair.png`：新生成的后发/前发分层图集，三种发型。中间刘海覆盖更充分，缩小暴露额头。
- `base-bodies.png`：白色T恤、浅灰短裤、简化赤脚。无独立手臂、手部或双腿透明间隙。
- `light-kit.png`：胸挂、作战衣裤和靴子，三种体型。
- `standard-kit.png`：标准防弹衣、作战衣裤和靴子，三种体型。
- `heavy-kit.png`：厚甲、腰部防护、加强裤装和靴子，三种体型。
- `helmets.png`：标准头盔与重型头盔，独立于身体和衣装。

本轮衣装以套装层展示，尚未把胸挂、护甲、内衬服装等逐件全部拆开；没有为不同脸型或发型重画同一套装备。后续逐件装备需要按当前身体挂点继续拆层制作。

## 实际组装方式

使用内置 `image_gen` 生成或修订六张部件图集，完整请求见 `prompts.json`。原始生成输出已复制到项目，未使用CLI/API备用路线。

`assemble.py` 将原部件像素嵌入SVG，使用每部件的来源矩形、缩放和锚点定位；不把整个人重新送入AI生成。`svg/` 和 `png/` 保存12组实际组合。显示衣装时隐藏被覆盖的基础衣层，保留颈部，避免白T恤从装备肩部穿出；戴盔时压住顶部刘海层，保留盔沿以下的发束与后发。当前戴盔实现是绘制裁切规则，尚未为每款头盔单独重画受压发型。

## 验证与边界

12组SVG均可解析并完成Godot渲染，PNG拥有透明通道、全身无画布边缘裁切。已肉眼检查额头对比和完整换装图。源图透明通道检查及运行时素材SHA256记录见 `verification.json`；`friendly_atlas.svg` 未改变。

这是正面静态美术审稿。AI源图仍需正式入库前的边缘清理与逐件贴图校准，当前不代表侧面、背面、动态表情或任意装备均已适配完成。

## 重建

先运行 `assemble.py`，再以Godot执行同目录 `render.gd` 输出PNG，最后运行 `compose.py` 生成审稿页与验证记录。
