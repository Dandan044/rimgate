## 生成与组装方式

四类部件各自提交一次生成，不按完整人物组合生成。参考了当前原稿的比例以及用户提供的种族模组图片的细节方向。原提示词完整保存在 `prompts.json`；脸型修正和头发透明清理的提示词分别保存在 `face-revision-prompt.txt` 和 `hair-cleanup-prompt.txt`。

人物组装没有再次调用AI重绘整个人。`assemble_svg.py` 将原PNG图集嵌入SVG，通过裁切视窗、位置、缩放和图层次序组装。原始PNG不改动；每个源部件仍可单独选择。`assembly-manifest.json` 记录四个身份部件ID与源图版本。`render_assembly.gd` 使用Godot渲染，`compose_review.py` 只负责审稿页排版。

## 验证与限制

六张原始/修订PNG均含RGBA透明通道；实际透明比例和边界见 `alpha-inspection.json`，由只读检查脚本 `inspect_alpha.py` 生成。四组SVG已渲染并肉眼检查。无手臂，腿部无透明分叉；本稿仅正面静态，没有运行时接入。

AI没有稳定遵守共同画布和锚点，因此本稿对每类部件进行了注册校准。头发仍存在半透明光晕，清理版本 `hair-cleanup-v2.png` 未达到合格标准，且线条变粗，组装仍选首稿。它具有透明通道，但这不等于边缘和实体不透明度符合正式贴图要求。当前应作为美术方向及部件组合验证，不能直接宣布所有未来装备、姿态与视角都能无调整适配。

脸型和五官互换可直接沿用模板；发型使用独立前后层。体型与基础衣着目前一起呈现，正式制作仍需把衣物、护甲、头盔等装备独立成层，并建立体型适配规范。
