# 四特征 SVG 细化审阅稿

本稿沿用 `pawn_four_parts_v1` 的正面轮廓和部件规格，供确认美术方向；没有替换游戏运行时资源。

## 看图

- `refined-review.png`：六组人物的裸头与独立头盔状态，以及透明图缩到 **实际轮廓高度 64px / 96px** 的效果。
- `face-hair-detail.png`：六组脸部与戴盔发型的近看图。
- `four-part-breakdown.png`：五官、脸、后发、前发、身体的独立层；三组交换部件 ID 的组合。
- `before-after.png`：与当前基础稿的同尺寸比较。
- `body-types.png`：同一套头部组合，只替换六种体型。

## 实际内容

共 76 张 SVG 和对应透明 PNG：六组裸头、戴盔、近看图，五官/脸型/前后发/身体独立层，戴盔时的前后发层，单独头盔，三组交叉组合，六张仅换体型的组合。源图为矢量路径与渐变，PNG 全身为 512×832，近看图为 608×608。

细化内容包括成束头发的遮挡和反光、面部明暗与弱腮红、虹膜二次反光、衣领折面、口袋翻盖/扣件/缝线、衣料折线，以及裤装和靴面的体积。外轮廓仍保持较细，额外细节优先通过成片明暗呈现，避免缩小后只剩杂乱线条。

## 分层与组合规则

四个身份特征仍为 `features`、`face`、`hair`、`body`。头发在绘制上分为 `hair-back` 和 `hair-front`；头盔是独立装备，不作为第五个人物特征。

局部头部挂点为 `(32, 34)`，脚底挂点 `(32, 94)`。按体型的 `neck_y - 34` 平移头部，保持头的大小和脸部坐标，避免把身体变宽时连脸一起拉宽。绘制顺序为后发、身体、脸型、五官、前发、头盔。每种发型保留单独的戴盔前后发变体，避免头顶从盔壳穿出。身体与脸共享肤色参数，换脸时同步更新颈部肤色。

身体没有独立手臂或手部路径；裤腿及靴子分别由连续轮廓绘制，只留弱中心缝。衣服目前随体型参数生成，展示了基本适配方式；任意后续装备仍需按共同挂点和遮挡规则制作，不能直接假定所有装备都能无调整适配。

## 验证及当前边界

已检查全部 SVG 可解析、全部 PNG 有透明背景、12 张全身组合无边缘裁切、三张交叉组合直接使用独立部件生成。运行时 `friendly_atlas.svg` 的 SHA256 与生成前一致。64px 和 96px 直接缩放图已经包含在审阅板，未以模糊放大图冒充实际游戏尺寸。

本稿为静态正面审阅；未制作侧面、背面、动态表情和游戏整合。64px 下衣服缝线会自然消失，主要保留头发、眼睛、脸和衣服的大明暗。此稿增加了视觉细节，但还不是参考种族 mod 那种逐像素润色的最终绘制稿。

## 再生成

运行 `make_refined.py` 生成 SVG，使用 Godot 执行同目录 `render.gd` 输出 PNG，运行 `compose.py` 生成审阅图并验证结构。`manifest.json` 保存部件 ID、挂点、绘制顺序和原运行时素材校验值。
