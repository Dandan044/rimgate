# 小人美术接入与短时实机审阅

2026-10-13。用户采纳AI方向，并要求保留初版、补充特征和四向/姿态、仅更换人物美术。之后按反馈修正长颈衔接、新增男性形象，并修正低蹲、持枪与装备分层。

## 本轮内容

- 默认使用AI部件人物，保留原SVG和旧PNG素材。暂停菜单的“小人外观”按钮可随时切回初版；也可用 `--pawn-style=classic` 启动。
- 九组头部特征，含三组明显男性设计：直眉、较窄眼形、宽下颌及一组胡茬；共36张四向头部视图。默认六名守军采用男女各三人的混合外观。敌方也复用混合特征。
- 纤细、宽肩、圆润三类体型与性别独立；基础白T恤短裤身体负责姿态，运行时只加载这一身体图集。上衣、裤装、三种胸挂/防弹衣与头盔分别叠加。以前的三种整套着装身体仅保留历史参考。
- 站立、蹲伏、卧倒和倒地复用；步行采用足部错相与身体轻微起伏。沿用现有瞄准、枪口、后座、透红受击、搬运、工事操作和医疗状态。
- 去掉重复的头部颈部留白，让下巴衔接衣领；短颈规则适用于站立、蹲伏和卧倒。新版医疗与工事操作不再额外画出独立手臂。
- 低蹲改为单膝低跪，身体高由26增至32像素，避免整个人被压扁。步枪枪托贴近胸肩，武器绘制在躯干之后、头盔之前；站立/低蹲/卧倒分别校准共享挂点和真实枪口。

素材源于内置 `image_gen`，原始图集和提示词在 `assets/art/pawns_ai/source/`，`tools/pack_pawn_art.py` 负责图集注册、裁切和重排。原始素材保留。当前上衣、裤装、防弹衣独立；裤装仍含鞋，面部和发型四向图仍按身份预组合，尚未拆出所有逐件装备和身份特征。详见 `PAWN_LAYER_CONTRACT.md`，不得将此预览声称为完整换装系统。

## 范围

主要修改人物资源、显示适配器和外观切换。此次还校准了 `scripts/sim/weapon_pose.gd` 的步枪共享挂点，实际投射物起点与可见枪口一起移动；工事挂点不变。不改变碰撞、格子占位、命中/掩体算法、护甲、射程、伤害、寻路、岗位或AI。所有人物体型和性别在本轮都是外观，不产生属性差别。

当前demo仍是三种姿态。蜷缩机制、更多动作帧和角色配装编辑器不在这次美术接入中。卧倒的上下方向由同一个真实横向姿态旋转注册，以保证颈端和脚端一致；未将图集错误方向直接投入运行。
