# Demo v0.2 游玩说明

解压Windows包，双击 `Rimgate.exe`。本地开发目录是 `build/release_v0.2_windows`；不要只复制EXE，旁边的 `Rimgate.pck` 也需要保留。开局停在准备阶段，可以先安排人员，再点右上“开始防守”。

## 先打一局

1. 按1选中第一人，右键左机枪，选择操控；第二人安排右机枪。左机枪主要覆盖西北，右机枪主要覆盖北面。
2. 给迫击炮安排一名炮手；再加入一名副手可以加快作业。按F后左键选地面，或先左键选中迫击炮，再右键敌人；每次命令只打一枚。
3. 其余人员守侧翼、搬弹和救人。右键工事可派人搬一箱补给；操作员缺弹时也会离岗自行搬运，期间工事停火。
4. Space随时暂停，安排新命令后继续。三波袭击在0:30、2:30、5:00到来，守住核心直到8:00。

## 位置和火力

活动单位各占一格，移动沿格心连续进行。多人点同一点会分配附近的合法格；沙袋可以翻越但不能站在上面，墙体阻挡通行和直射。

沿射线的所有沙袋都可能拦弹，目标无需贴近沙袋。射手靠近出射侧的沙袋时阻碍较少；多道掩体也会挡己方火力。不要把步枪兵放在己方机枪的弹道中间。爆炸、弹片和流弹都会误伤友军。

常规步枪无干扰时约3秒一轮；谨慎约4.5秒，更重视精度；压制短暂准备后持续开火，精度低且耗弹快。瞄准锥与进度反映实际准备状态，移动、转向和压制会影响射击。固定工事有各自的射界、装填和作业周期。

右键敌人指定个人武器目标；正在操控工事时，应先左键选择工事再右键敌人。指定目标暂时被挡或离开射界时会守位等待，可以重新指定目标。新右键立即接替旧菜单或轰击选点，不需要先左键空白。

## 救护

受伤后持续出血，生命降低到阈值会倒地，归零死亡。右键伤员可以现场急救；昏迷者也可搬进右后方救护区，安置后继续治疗。搬运途中仍出血，搬运者不能开火。治疗只止血，随后缓慢恢复；本局不要依赖重伤者立即重返前线。

自动AI优先攻击有生力量，不自动补刀倒地者。结果页可“重新部署”。本Demo聚焦单次战斗，暂不包含经营、建造、科研或中途存档。
