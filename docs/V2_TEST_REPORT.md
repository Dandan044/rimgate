# Demo v0.2 验收记录

本记录对应第二版，第一版的 [验证报告](TEST_REPORT.md)、[构建记录](BUILD_PROVENANCE.md) 和录像保留作历史。引擎为 Godot 4.7.2，Compatibility / OpenGL 3.3。自动化输入、目视截图、实时性能与离线录像分别记录，尚未进行的项目不记为通过。

## 源码与规则

- 四套源码回归：等待最终整合运行。
- UI 契约：28 项通过；包含实际 Viewport 连续右键、选工事指定攻击、HUD 不穿透、显示碰撞时刻播放声音、透红及暂停。
- 战斗采样：80,000 发实际弹道。裸露到达率 0.5971；基础命中 0.6、单掩体拦截 0.5 时约 0.2942；拦截上限 0.9 时约 0.0589；两道独立 0.5 掩体约 0.1592。空间索引与穷举路径进行 282 步精确状态/RNG 对照。
- 常规步枪完整周期约 3 秒，谨慎约 4.5 秒；压制短瞄准后持续机械射速。实际枪口、转向稳定、枪口挡墙、工事目标等待、迫击炮单发与不追踪均有回归。
- 格子专项：同点群移预占、狭道侧袋双向让路、对角交叉、途中停止、伤员可穿过但非最终落点、双炮手固定座位、苏醒取空格与救援分格安置。

本版掩体公式与数值是 [v0.2 默认参数](../DEMO_V2_PLAN.md)，可以继续调整，不代表完整游戏最终平衡。

## 完整防守

等待冻结源码后重新汇总五种公开命令防守方案及实时 Windows 回放。所有方案保持原始人员、血量、弹药、敌人和波次；使用固定种子，不代表多种子胜率。固定指令会利用已知波次时刻提前准备炮击，不能据此声称普通首次试玩也同样容易。

## 输入、画面与音频

720p 与 1080p 实际视口截图已目视核对版式。原有 SVG 人物轮廓和配色保留，工事增加顶侧面、接地阴影与轻微磨损。音频为 24 个 48kHz/16bit/单声道运行资源，离线检查没有削波；固定 24 个空间声音节点按显示事件播放。音源许可见 [音频说明](AUDIO_V2.md)。尚未将自动化资源/时序检查描述为人工听音评价。

实际 Windows 输入、最终实时性能、长运行、结果页、录像与构建哈希待补齐。
