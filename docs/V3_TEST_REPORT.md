# Demo v0.3 验收记录

状态：开发已接入，最终Windows导出验收进行中。本文件尚不证明第三版交付完成，未运行或未通过的检查不记为通过。

## 已取得的源码证据

- 世界、单位、战斗与表现基线在改动前通过；新增单位回归覆盖最低可射姿态、分级压制、蜷缩、岗位暂停、队形和火控。
- 战斗5000发静态采样与最终命中预算差0.773个百分点；迫击炮5000发覆盖概率与预算差约0.3个百分点。360步查询/不查询两组的状态、事件及战斗随机数一致。
- 实际Viewport输入检查已覆盖右拖、暂停分配、主选、混合设置、独立火控、概率/Alt、死亡时间和分辨率。交叉审查另发现选择路由、自动姿态目标、装填接续与墙角擦线问题；修复后的最终检查以最后运行报告为准。
- 人物分层、敌方固定外观、A地表与16邻接建筑资源已接入。原稿和初版人物保留；图集/静态截图仅证明对应表现，不能代替实机整局及性能。
- 已有当前规则下480秒合法胜利记录，另有常规机枪策略失利的对照；战斗仍需策略安排，不能把单发精度改善写成所有风格已完全平衡。

## 最终导出待验收

需用同一版本EXE/PCK完成：完整回归、实际输入、2–3分钟画面短测、65秒实时性能、480秒胜利和重开、30分钟稳定性与进程内存检查、运动/暂停/音频证据，以及交付包和源码提交一致性校验。

最终报告将记录实际PCK哈希、运行命令、检查结果和限制；此处不预填通过、性能数值或不存在的交付哈希。
