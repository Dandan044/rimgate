## 实时性能

独立Windows压力场景运行65秒，前5秒预热，随后60秒采样；6名己方、24名敌人、弹丸峰值256。夹具恢复生命、补充弹丸以稳定负载，只测性能，不用于胜利或平衡验证。

已测平均 **145.24 FPS**，平均帧耗时 **6.885 ms**、P95 **12.014 ms**，8716帧，节点峰值127。逻辑视口1600×900，窗口1920×1080，Windows缩放下实际渲染2304×1296；不能写成原生1920×1080渲染。

报告为 `build/reports/vector_benchmark.json`。该次早于最后一段弹道/地面细调。修订构建随后完成普通交战与压力复测：

- 普通交战：35秒运行、5秒预热，4786帧；平均159.48FPS、平均6.270ms、P95 7.222ms，弹丸峰值12。报告 `vector_normal.json`。
- 最后生命周期修正后的压力复测：65秒运行、5秒预热，8412帧；平均140.18FPS、平均7.134ms、P95 12.716ms，弹丸峰值256。报告 `vector_final_benchmark.json`。

两次均采用上述硬件及逻辑/窗口/渲染分辨率，报告无失败项。仅证明本机这些场景通过门槛，不代表低配置机器表现。

同一仿真压力夹具的300次微基准，弹丸部分由约17.75ms降至约3.43ms，整步由约20.39ms降至约6.13ms。这是无窗口微基准，与显示帧采样分开。
