# 小人身体、姿态与装备分层约定

2026-10-13。按用户反馈纠正此前“整套着装 × 姿态”的临时实现。

## 核心要求

本规范的逐件换装要求适用于己方可控人员。2026-10-13用户另行确认：敌方使用固定敌种完整外观，身体/服装/防护/遮面装备可合并，只有武器必须独立；保留四向和必要姿态。敌方不需要单独逐稿审查，已计入后续版本计划，见 `DEMO_V2_FEEDBACK.md` C11。该例外不改变己方的长期分层目标。

身体负责体型与姿态；装备叠加到身体上。禁止以人物身份、上衣、裤子、防弹衣、头盔的组合为单位生成整个人物图。新增一件装备，只增加该装备自己的必要视图，不连带重做其他装备组合。

不同朝向、姿态、明显不同的体型可能仍需要装备适配图或形变。这是单件装备的适配成本，不是装备组合数量的乘积。SVG、AI生图都不能自动保证适配，必须按统一的挂点和尺寸审阅。

## 第三版实现

第三版保留下述人物预览的独立身体和衣甲，新增 `assets/art/v3/` 中3种脸型、6组五官及其6种表情、6组前后发；运行时由 `appearance_profile` 分别选择四特征。三类体型使用肩、腰、臀和挂点的非均匀轮廓适配，不仅统一横向拉伸。蜷缩与倒地使用独立显示状态及相应分层形变；敌方使用固定整人姿态PNG、独立武器，不计算复杂表情。

这是素材组合能力，不代表已经提供玩家配装或捏人编辑界面。表现、输入和实机验收见 `V3_TEST_REPORT.md`，不能使用下方旧预览的通过结果代替第三版最终验收。

## 2026-10-13人物预览的历史实现

- `body_base.png` 是唯一运行时身体图集：白T恤、短裤的最简基础着装，四向、站立/低蹲/卧倒。体型通过三类宽度适配；尚未拥有三套独立身体骨架。
- `uniform_top.png` 为独立上衣；`uniform_legs.png` 为独立裤装（当前含靴子，后续鞋类需要再拆）。
- `vest_light.png`、`vest_standard.png`、`vest_heavy.png` 只有胸挂/防弹衣，没有身体、裤装、头部。
- 头盔独立。九组头部目前仍预组合了脸型、五官和头发，不宣称已完成四个特征全部独立拼装。
- 身体、裤装、上衣、防弹衣、武器、头部、头盔按层绘制。上衣/防弹衣依托躯干挂点；裤装依托腰部与足点。站立/蹲伏共用刚性防弹衣视图；卧倒采用背部视图按身体轴旋转。
- 运行时的衣物选择分别是 `top`、`legs`、`vest`、`helmet`，没有包含服装组合名称的纹理查找。
- 以前的 `body_light/standard/heavy.png` 及原始整套图保留为历史参考，当前组件渲染器不加载这些整套身体。

这只是分层基础与少量装备适配验证，不包含背包、胸挂互斥规则、装备编辑UI、任意装备全覆盖或完整角色美术生产线。

## 挂点与绘制合同

逻辑足点不变；一个图集格为256像素，四向列顺序南、东、北、西，姿态行顺序站立、低蹲、卧倒。运行时站立身体高38像素、低蹲32像素，头部覆盖领口，避免重复颈部。低蹲是单膝低跪，禁止统一压扁整个人物来模拟蹲伏。

上衣覆盖身体前56%的躯干区域，裤装从45%的腰部区域开始，预留重叠消除接缝；卧倒时这些区域按朝向映射到长轴。武器在身体/衣物之后、头/盔之前绘制，枪托靠近胸肩，不添加独立手臂。

武器挂点与真实枪口共同由 `scripts/sim/weapon_pose.gd` 定义。此次按新身形收紧挂点，并分别校准站立、低蹲和卧倒，实际子弹起点随可见枪口同步调整；没有改变射速、命中、伤害、掩体算法、AI或格子占位。

## 后续素材验收

新增装备先在同一基础身体上独立穿脱，再与至少两种其他层组合；检查四向、三姿态的颈口、腰口、遮挡、持枪和头盔露发。不得把换一整张穿衣人物图描述成独立换装。

## 来源与审阅

独立装备原稿与内置AI生图提示词在 `assets/art/pawns_ai/source/modular-*.png`、`modular-prompts.json`。低蹲基础身体在 `crouch-v2-base.png`。其他 `crouch-v2-light/standard/heavy.png` 是本轮转向前的临时稿，仅保留参考，不作为正式分层资源使用。

`--pawn-fit-review` 是明确标注的受控视觉夹具：真实游戏渲染、普通攻击/姿态命令、真实投射物；固定位置、目标血量/弹药/AI和关闭波次，仅验证持枪、动作与分层，不证明平衡或性能。最后12秒暂停并通过显示覆盖逐层穿脱同一小人的装备，不代表已经提供玩家配装UI。
