# Demo v0.3 游玩说明

解压 Windows 包，双击 `Rimgate.exe`。请保留同目录的 `Rimgate.pck`；不要只复制 EXE。本版是一张固定地图上的 **8分钟防守战斗**，开局停在准备阶段，可以先安排人员再点右上“开始防守”。

## 先打一局

1. 按1选中第一人，右键左机枪，选择操控；第二人可安排右机枪。左机枪主要覆盖西北，右机枪主要覆盖北面。
2. 迫击炮可由一人操作；加入第二人可加快装填。按F后左键指定地面，或先左键选择迫击炮，再右键敌人。每条有效命令只发一枚炮弹；提前装膛不会自行发射。
3. 其余人员守侧翼、搬弹和救护。右键工事可派人搬一箱补给；操作员缺弹时也可能离岗搬运，期间该岗位暂停作业。
4. Space随时暂停或继续。三波袭击在0:30、2:30、5:00到来，守住核心直到8:00；核心被摧毁或全员阵亡则失败。

## 选择、移动和队形

- 左键选择人员或建筑；拖框选择多人，Shift增选，数字1–6选对应守军。多选时最后点击者为主选，框选默认最小编号；状态栏和概率提示会标明主选。
- 右键空地，松开时确认移动。多人短点击会得到不同的格心落点；暂停时已经完成分配，继续后按这些格子移动。
- 多人按住右键拖动：**按下点是队列中心，拖线方向是队列轴线**，人员沿拖线排开。拖得越长，间距越大，间距限制为1–4格；箭头表示到达后的朝向。预览显示修正后的实际落点，空间不足会标红并拒绝整组命令。
- 新右键可直接接替原菜单或迫击炮选点，不必先左键空白。HUD上的点击不会穿透到战场。
- WASD或中键拖动平移镜头，滚轮缩放。右上“地图”展开或收起小地图；“菜单”中可切换初版小人外观、重新部署或退出。

活动单位一人占一格，格间连续移动。沙袋可以翻越，但不能停在上面；墙体阻挡通行和直射。

## 火力、概率和姿态

底栏分别设置姿态、作战风格、停火/自由开火、严格锁定/优先攻击；多人设置不一致时显示“混合”。这些选项彼此独立。选择人员时修改其单兵武器；选择工事时修改工事自身的火控，换炮手不会带走工事设置。

右键敌人指定单兵目标；正在操控工事时，应先左键选择工事，再右键敌人。严格锁定会在目标暂时不可攻击时守位等待；优先攻击允许临时攻击其他合法敌人。停火保留已有目标；迫击炮停火会挂起已有轰击命令，恢复后接续。

悬停敌人时，所选人员或有人操作的工事会显示**最终单发命中率**，已经考虑当前精度、掩体和中途人员。Alt展开因素、掩体段、人员阻挡、友军豁免和友伤风险。该数字采用**当前状态快照**，不提前计算未来瞄准获得的稳定度，也不预测飞行期间目标移动。空仓、装填、瞄准等“尚未就绪”状态会单独提示，不等于射击精度为零。迫击炮显示的是“目标位于爆炸范围内的概率”，不是单发直接命中率或造成伤害的概率。

常规步枪无干扰时约3秒一轮；谨慎作战准备更久、单发精度更高；压制作战开火更快、单发精度明显更低，耗弹也更快。瞄准锥和进度反映实际准备过程。征召人员空闲静止后会提前补弹；工事需要合法操作员和实际库存才能装填。

自动姿态在定点交火时选择能够开火的最低姿态；手动锁定不会自行起身。贴近沙袋卧倒时，枪口可能低于沙袋而无法出射；空地卧射仍然可行。受压制会强迫蹲伏、卧倒，切换时打断动作，完成后可以继续兼容的爬行、射击或工作。持续受压会进一步蜷缩，此时全部主动行动暂停；再继续受压可能溃逃，解除征召并站立避险，10秒内无法重新征召。工事需要站立或蹲伏操作，炮手卧倒时岗位保留但暂停。

连续穿过的同属性沙袋按一段结算，真正分开的防线分别判定。保护效果不要求被攻击者贴近沙袋；出射侧靠近沙袋时阻碍更小。墙体仍确定阻挡，不能用贴近减免绕过。中途人员也会挡弹；贴近射手的友军有局部出射豁免，敌人和原目标没有。远处友军、流弹、爆炸和弹片仍可能造成误伤。

## 救护和结束

受伤可能持续失血，生命低于阈值会昏迷，归零则死亡。小队卡和详情显示按当前生命/失血速度估算的死亡时间，单位为游戏时间；无失血显示“稳定”。它不包含后续受击，也不提前计入尚未完成的治疗。

右键伤员可现场止血；昏迷者可搬到右后方救护区，安置后继续治疗。搬运途中仍失血，搬运者不能开火。清醒蜷缩者可以接受外部治疗，但不属于可搬运的昏迷伤员。治疗只止血，随后缓慢恢复，不保证重伤者立即重返前线。自动寻敌优先攻击有生力量，玩家仍可强制指定倒地目标。

结果页可以重新部署。本Demo暂不包含经营、生产线、科研、玩家建造/拆除、配装编辑器、长期存档或中途存档；人物和装备的分层表现已接入，不能据此理解为已有完整装备管理玩法。
